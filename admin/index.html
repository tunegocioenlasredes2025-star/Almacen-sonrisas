Entrar al panel

Desde acá cargás, editás y sacás productos del catálogo de la web. Los cambios se publican solos en 1 o 2 minutos.

¿Cómo consigo el código?
  1. Entrá a GitHub con la cuenta de la agencia y abrí crear un token nuevo.
  2. Ponele de nombre Panel Almacén de Sonrisas y elegí la duración más larga.
  3. En Repository access elegí Only select repositories → Almacen-sonrisas.
  4. En Permissions → Repository permissions, poné Contents en Read and write.
  5. Tocá Generate token, copiá el código (empieza con github_pat_) y pegalo acá.

El código sirve de contraseña: no lo compartas ni lo mandes por redes.
